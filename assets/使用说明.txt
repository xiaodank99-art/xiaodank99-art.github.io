Codex 用量监控 2.5.9 · 通用发布版

一、安装与启动
运行 CodexUsageMonitor-2.5.9-win-x64-setup.exe，按中文向导完成安装。默认仅为当前用户安装在 %LOCALAPPDATA%\Programs\CodexUsageMonitor.Pearl，可从桌面或开始菜单启动。
支持 Windows 10（1607 或更新版本）/ Windows 11 的 Intel、AMD 64 位电脑，需要 .NET Framework 4.8 或兼容版本；不支持 32 位 Windows、Windows ARM、Windows Server、macOS 和 Linux。
安装包不会安装 Codex。账户数据需要本机可用的 Codex 安装和登录状态。

二、首次运行
打开“设置 → 环境检测与路径设置”，查看系统、Codex 和日志路径。自动发现失败时，可手动选择 Codex 程序与日志目录。
默认日志目录为当前用户的 .codex；也可使用 CODEX_HOME、CODEX_MONITOR_HOME。完整日志目录通常包含 sessions、archived_sessions 等子目录。
没有日志时不会生成虚构数据；不支持的账户接口会显示不可用原因。账户与本机统计范围不同，不相加。
订阅到期日及具体时间由你手动填写，与额度重置时间独立。剩余额度不高于 30% 时显示提醒；订阅不足 7 天时提示，设置具体时间后不足 24 小时将显示按分钟计算的倒计时。仅填写日期时不会虚构到期时刻。主窗口最小尺寸为 1100×800 逻辑像素。

三、日常使用
保留浅色界面、卡片轮廓、按钮弹性和既有数据页。
本机日志每 15 秒增量刷新；账户与额度每 60 秒刷新；F5 可立即刷新。隐藏/最小化时仍按原规则更新数据，恢复窗口立即显示最新结果。
自动浮窗跟随可识别的 Codex 桌面窗口，显示当前聊天的缓存命中率、累计 Token 和订阅剩余额度，文字样式按 Codex 工具栏适配。定位失败时可使用可拖动的后备浮窗；不会把最近活跃聊天冒充成当前聊天。可在设置中选择手动浮窗并重置位置。
浮窗的“剩余 96%”指订阅使用额度，优先显示每周限额，与主页七天额度使用同一份 Codex 账户数据；它不是当前聊天的上下文剩余比例，也不是按累计 Token 估算。账户与浮窗额度约每 60 秒读取一次，可能与 Codex 界面存在短暂刷新时差；F5 可立即刷新。读取失败、数据过旧或已到额度重置时间时，会提示上次值或待刷新，不把过期数字当作最新额度。
检测到旧蓝色版仍在运行时，本版会暂停自己的浮窗，避免两个浮窗重叠。可在主窗口“设置”页的“环境与兼容”区域点击“结束旧版后台，恢复浮窗”，再由本版显示浮窗（按钮仅在检测到旧版时出现，不在环境检测弹窗内）；旧版文件和备份仍然保留，不会被打进发布包。关闭主窗口后，浮窗开启时程序可能仍留在托盘；完全退出请使用设置页、托盘菜单或 Ctrl+Q。

快捷键
Ctrl+1 总览；Ctrl+2 聊天；Ctrl+3 用量趋势；Ctrl+4 数据明细；Ctrl+5 设置。
Ctrl+F 搜索；Ctrl+7 七天；Ctrl+Shift+5 十五天；Ctrl+0 三十天。
Ctrl+O 浮窗开关；Ctrl+Q 完全退出；Ctrl+E 环境检测与路径设置。

四、升级与卸载
升级前完全退出监控，再运行新安装包；安装程序不会强制关闭 Codex 或删除旧版项目。
从 Windows“已安装的应用”中卸载 Codex 用量监控。卸载保留 %LOCALAPPDATA%\CodexUsageMonitor.Pearl 下的设置、缓存，以及所有 Codex 原始日志，重新安装可继续使用。
如果使用免安装压缩包，必须完整解压后运行，不能只复制主 EXE。它同样依赖上述系统运行时。
